# LocalMart

A hyper-local marketplace app connecting customers with nearby stores.

## Tech Stack

### Frontend
- React + TypeScript
- Leaflet.js (maps)
- Razorpay (payments)

### Backend
- Node.js + Express + TypeScript
- MongoDB (Railway)
- JWT Authentication

---

## Backend

### Setup
1. cd backend
2. npm i
3. Create .env:
   MONGO_URL=your_railway_mongodb_url
   PORT=5000
4. node --watch index.ts

### Folder Structure
src/
  controller/
  db/
  models/
  routes/
  types/
